Phase 2: Return Request and related APIs\n\nThis patch introduces Return Request DocType and API endpoints to request and approve returns.\n- create_return_request(supplier, items, linked_purchase_receipt, linked_purchase_order, reason)\n- approve_return_request(return_name, approve=True)  (System Manager only)\n\nOn approval the serials listed in the Return Request will be marked as 'returned' in Serial Pool and bound to the Return Request (reserved_for).\n\nNotes: For safety this change does NOT auto-create financial documents (Credit Note) or Stock Entries. Those can be added in a follow-up step after we agree on warehouse mapping and accounting flows.\n
